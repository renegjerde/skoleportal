# PausePuls

Pauseaktiviteter for lærere på 1.–7. trinn.

## Innhold
- `index.html` – webappen, klar for GitHub Pages.

## Publisering med GitHub Pages
1. Opprett et nytt GitHub-repository.
2. Last opp `index.html` (og denne README-filen) til repositoryets rot.
3. Gå til **Settings → Pages**.
4. Under **Build and deployment**, velg **Deploy from a branch**.
5. Velg `main` og `/ (root)`, og trykk **Save**.
6. Vent til GitHub Pages har publisert siden. URL-en vises i Pages-innstillingene.

## Teknisk merknad
Dette er en statisk webapp uten backend. Favoritter lagres lokalt i nettleseren. Generatoren er foreløpig en malbasert demonstrasjon, ikke koblet til en AI-tjeneste.
