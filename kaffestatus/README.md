# ☕ KaffeStatus Web App

En stilfull, lys og skandinavisk Progressive Web App (PWA) som viser kaffetilgjengeligheten på pauserommet i sanntid.

## 🚀 Slik publiserer du på GitHub Pages

1. **Opprett repository:**
   - Gå til [GitHub.com](https://github.com) og opprett et nytt offentlig repository (f.eks. `kaffestatus`).

2. **Last opp filene:**
   - Last opp `index.html` og `README.md` til repositoryet.

3. **Aktiver GitHub Pages:**
   - Gå til repository-innstillinger (**Settings** -> **Pages**).
   - Under **Build and deployment** -> **Source**, velg `Deploy from a branch`.
   - Velg `main` (eller `master`) som branch og klikk **Save**.
   - Etter 1–2 minutter er appen tilgjengelig på: `https://<ditt-brukernavn>.github.io/kaffestatus/`

4. **Bruk på iPhone / Android:**
   - Åpne lenken i Safari (iPhone) eller Chrome (Android).
   - Trykk **Del** / **Meny** -> **Legg til på hjemmeskjerm** (Add to Home Screen).
